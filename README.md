# Silvialab

Alat kimia berbasis web (tanpa build): tabel periodik + perakit molekul, jelajah senyawa (PubChem), biomolekul & virus (RCSB PDB), editor molekul 2D, dan simulasi genetika/CRISPR/obat. Responsif untuk HP.

Buka `index.html` di browser, atau jalankan `python -m http.server 8000`. Tab Jelajah dan Biomolekul butuh internet.

Catatan: simulasi bersifat edukasi, bukan prediksi klinis.
